01 API 的本质

不接 API 是手工对话，接 API 是把 AI 接进生产线

很多人以为 API 只是“程序员版 ChatGPT”。其实更准确的说法是：API 让 AI 从一个聊天窗口，变成你系统里的一个可调度能力。

不接 API：适合探索

  • 打开豆包、Kimi、ChatGPT，手动输入需求。
  • 每次提示词靠人复制，版本靠人记忆。
  • 适合头脑风暴、一次性文案、临时问答。
  • 问题是不可批量、不可追踪、不可稳定复现。

接 API：适合生产

  • 把模型能力接入脚本、后台、工作流或自动化工具。
  • 同一套规则可以批量跑 100 张图、100 条文案、100 个分镜。
  • 输入、输出、成本、失败原因都能记录。
  • 可以接质检、接知识库、接素材库、接人工确认。
一句话

聊天窗口是个人效率工具

适合一个人临时做一件事，快，但结果靠手感。

一句话

API 是组织生产能力

适合把同一套方法重复执行，批量、可记录、可复盘。

一句话

Harness 是质量管理系统

适合把品牌、角色、合规、素材、审批都管住。

02 三层架构

模型负责生成，管线负责执行，统一管控层负责不跑偏

你给的图已经把核心讲清楚了：底部是模型，上面是统一管控层，再上面才是脚本、分镜、图片、视频这些产出模块。

任务调度层 接收需求，拆解任务，分配给脚本、分镜、图片、视频等模块。
管线模块 脚本生成、分镜设计、图片生成、视频剪辑，每个模块只做自己擅长的事。
统一管控层 IP 规范、合规校验、质量审核、知识库和素材沉淀，是 Harness 的核心。
模型层 豆包 4.0 可以做主力，DeepSeek 可以做批量文本任务。模型可以替换，规则要沉淀在 Harness。
没有统一管控层，角色会漂 第一张是毛绒三花猫，第三张可能变成动漫猫、真猫、塑料玩具或另一只吉祥物。
没有统一管控层，风格会漂 同一支片子里，有的像羊毛毡，有的像 3D，有的像实拍，剪在一起马上穿帮。
没有统一管控层，品牌会乱 围裙 Logo、中文标识、活动口径、门店信息都可能被模型瞎编。
没有统一管控层，经验沉淀不下来 今天靠人调出来的好效果，明天换人、换模型、换提示词，又从头试错。

03 自动化产出

动画短片不要让一个提示词硬扛，拆成可检查的流水线

复杂动画最容易失败的地方，是把脚本、分镜、角色、场景、运镜、文字、剪辑全塞进一个提示词。正确做法是拆开，每一步都留下可检查结果。

Step 1 需求卡 目标、受众、平台、时长、比例、禁区。
Step 2 脚本 一句话卖点，三段情绪，结尾行动。
Step 3 分镜 每镜头时间、画面、动作、镜头运动。
Step 4 关键帧 先出图，锁角色、材质、食物和场景。
Step 5 视频化 用图生视频，动作小，镜头稳。
Step 6 后期 Logo、字幕、门店数、活动文案后期加。
Step 7 质检入库 通过样例沉淀，失败原因写回 Harness。

餐饮店可以自动化什么

  • 经营日报：每天销售额、客流量、翻台率、滞留时长、公众号数据和大众点评差评投诉，自动汇总成日报并给出异常分析。
  • 外部内容运营：大众点评差评投诉自动识别、生成回复建议并按品牌口径处理；公众号选题、文案、配图建议、排版和发布计划可以自动撰写。
  • 员工与协作日报：接入飞书，自动整理员工每日产出、沟通响应、任务推进、问题阻塞和需要店长跟进的事项。
  • 门店服务监控：接入监控逐帧分析迎客、服务表情、是否面带微笑、顾客等待时长、顾客吃咖喱时的表情和停留行为。
  • 厨房与排班监控：分析厨房卫生、出餐是否执行 SOP、是否有人未按标准操作、人力是否饱和、是否需要两班，以及下午空闲时段员工状态。

动画美术可以自动化什么

  • 角色与 IP 规范：角色圣经、不可变识别点、动作边界、材质边界、服装道具和负面方向统一管理。
  • 动画前期：脚本拆解、分镜草案、镜头表、关键帧提示词、参考图包和风格板批量生成，再由美术挑选修正。
  • 视频生成管线：关键帧、图生视频、镜头运动、字幕留白、后期文字、音乐节奏和多版本短视频组合。
  • 自动审稿与美术质检：检查角色漂移、羊毛毡质感不稳定、食物不诱人、文字错误、镜头不可剪、前后镜头风格不一致。
  • 视频平台运营：按抖音、小红书、视频号、B 站等平台要求，自动适配标题、封面、字幕、比例、标签和发布时间，并在发布前做平台规则质检。

04 羊毛毡质感稳定

提示词不是越长越好，而是每个镜头都要锁同一套身份和材质

质感不稳定通常不是模型“不听话”，而是你没有把“角色身份、材质、镜头、负面方向、后期文字”拆清楚。

先锁参考图

最终画面不要只靠文字生成。上传全身参考、脸部材质参考、成功样张，让模型跟图，不要让模型重新设计。

每个镜头重复身份锁

不要只在第一镜写“毛绒三花猫”。每一镜都写清同一个角色、同一材质、同一服装、同一表情边界。

把文字交给后期

AI 生成图像时尽量不要承担复杂中文。围裙 Logo 可留干净区域，最终用可控工具叠字。

羊毛毡 IP 关键帧提示词模板 可直接改品牌名和角色设定 
基于上传参考图中的同一个角色，生成一张 9:16 竖屏关键帧。
角色必须保持：三花毛绒猫厨师，圆形白色大脸，头顶左侧黄色毛毡 patch，右侧棕色毛毡 patch，小黑豆眼，棕色小鼻子，简单微笑，粉色方形腮红，白色软厨师帽，棕色布料围裙，短绒毛、羊毛毡、手工缝线质感。

画面风格：暖黄微缩厨房，木质台面，浅景深，柔和商业广告灯光，干净、温暖、有食欲。
镜头内容：角色轻轻搅拌一锅咖喱，前景有干净诱人的咖喱饭，咖喱浓稠亮泽，米饭颗粒饱满，炸物酥脆，酱汁边缘干净。

不要生成除围裙品牌区以外的其它文字。围裙 Logo 如果无法准确生成，保留干净空白区域，后期叠加。
负向：不要真实猫，不要真人，不要其他动物，不要动漫大眼，不要塑料 3D，不要陶瓷质感，不要脏厨房，不要暗黑风，不要咖喱变成一坨不明物，不要乱码文字，不要多余肢体，不要夸张动作。
常见失败 原因 修法
羊毛毡变塑料 3D 提示词只写“可爱吉祥物”，没有材质锁。 每镜写“短绒毛、羊毛毡、手工缝线、柔软布料”，负向写“不要塑料、陶瓷、金属、低质 3D”。
角色越生成越不像 模型把每张图当新角色设计。 用同一套参考图，提示词写“同一个角色，不重新设计，不改变物种、脸型、头顶色块和服装”。
咖喱没有食欲 只写“咖喱”，没写商业食物标准。 写“浓稠亮泽、边缘干净、米饭颗粒饱满、炸物酥脆、食材结构清楚”，拒绝泥状、剩菜、灰暗。
中文 Logo 乱码 图像模型不擅长稳定生成复杂文字。 不要让模型生成复杂文案。正式 Logo、门店数、活动信息在后期或设计工具里叠加。

05 伽喱博士 IP Harness 样例

把“看着像”改成“必须满足这些检查项”

对 IP 来说，Harness 不是提示词库，而是一份可执行的品牌质检标准。通过就进入下一步，不通过就重生成或人工修。

角色锁 圆脸白色毛绒三花猫，黄色和棕色头顶色块，小黑豆眼，粉色腮红，白厨师帽，棕色围裙。
Logo 锁 围裙胸前必须是“伽喱博士 Dr.CURRY”。如果模型写不准，就留空后期加，不接受乱码。
食欲门禁 咖喱要浓稠亮泽，米饭颗粒饱满，炸物酥脆，绝不接受泥状、脏污、剩菜感。
动作边界 轻轻搅拌、端盘、挥手、眨眼。不要大幅奔跑、跳跃、夸张表演。
产出策略 先跑 8 秒小样，稳定后再做 20 秒。长片漂移就拆成 5 个镜头分别生成，再进行合成或者人工转场后期。

06 Codex 怎么用

Codex 不是聊天框，是会读工作区、改文件、跑验证的执行型助手

给 Codex 的正确方式不是“帮我想一个提示词”，而是把规范、素材、失败样例放进工作区，让它按文件里的 Harness 产出、检查和迭代。

准备工作区

把规则写成文件

例如 `harness.md`、`ip-character-bible.md`、`visual-style-board.md`、`negative-directions.md`。这些比散落在聊天记录里的经验可靠。

让 Codex 执行

把任务说成动作

让它读取规范、生成分镜、写提示词、整理 QA 表、更新失败原因，而不是只要一段灵感。

用文件沉淀

成功和失败都入库

好图沉淀成参考图，坏图沉淀成负面方向，下次自动复用。

保留人工门禁

关键节点人确认

角色定稿、活动口径、Logo、门店数、合规承诺都应该人工确认，不让模型自己定。

生成 5 镜头分镜 读取 carry-doctor-ip-video/references 下的 Harness 和角色规范。为“伽喱博士 7 周年短片”生成 15 秒 5 镜头分镜，每镜头给画面、动作、运镜、后期文字和拒绝标准。
修提示词稳定羊毛毡质感 这组图里第 3 张变成塑料 3D，第 4 张咖喱像泥。请根据 negative-directions.md 改写每镜头提示词，并给一份重生成策略。
做图像质检 检查 assets 里的关键帧是否符合 harness.md。按角色一致性、食物食欲、文字安全、画面可剪辑性打分，指出必须重做的镜头。
把经验写回 Harness 把这次成功样例和失败样例总结成 6 条可复用规则，补充到 visual-style-board.md 和 negative-directions.md，不改动无关内容。

07 周日讲课节奏

45 分钟版本：先讲痛点，再讲架构，最后现场演示

听众不是来听概念名词的。建议每 8 到 10 分钟就回到一个具体例子：菜单图、短视频、角色漂移、Codex 实操。

0 到 5 分钟
开场：为什么大家用 AI 还是不稳定 展示两张咖喱博士图，说明“好看一次”和“稳定产出一百次”是两回事。
5 到 13 分钟
API 和不接 API 的区别 用餐饮活动图批量生成举例：聊天窗口是手工试菜，API 是接进厨房生产线。
13 到 23 分钟
Harness 和统一管控层 讲 IP 规范、合规、质量审核、素材库。强调模型可以换，Harness 是自己的资产。
23 到 33 分钟
动画自动化产出链路 从需求卡到脚本、分镜、关键帧、视频、后期、质检，拆成 7 步，每步有输入输出。
33 到 40 分钟
羊毛毡质感和提示词实战 讲参考图优先、身份锁、材质锁、负向提示、文字后期叠加，现场改一段提示词。
40 到 45 分钟
Codex 实操和结尾 展示如何让 Codex 读取 Harness、生成分镜、检查关键帧、把失败原因写回规范。

08 可以直接带走的结论

真正值钱的不是某个模型，而是你能否把经验变成规则

这套讲法最后要落在一个清楚结论上：AI 的能力会越来越便宜，能把 AI 接进业务并管住的人会越来越值钱。

为什么要用 API

为了批量、自动、可记录、可复现，把 AI 从聊天工具变成生产系统的一部分。

为什么要用 Harness

为了统一 IP、风格、合规、质量和知识沉淀，让 AI 产出可控，而不是靠运气。

为什么要用 Codex

为了让 AI 不只回答问题，而是能在你的文件、规范和素材里持续执行、验证和迭代。

AI 不是神谕，而是预测系统

今天分享的核心内容，其实不仅仅是 Harness 的概念，也不仅仅是 AI 工具的用法，而是 AI 在这个时代真正能带来的能力升级。

人生是一个不确定系统

人生不是“努力 A，就一定得到 B”的线性结算。真正影响结果的，是机会窗口、行业变化、合作网络、信息差、路径依赖、偶然事件，以及我们自己在压力下的判断质量。

所以高级能力不是追求一个确定答案，而是不断下注、观察反馈、修正模型。

人为什么会迷信、信风水？不是因为人缺乏理性，而是因为人在不确定中太需要确定性。人会本能地找模式、找因果、找控制感。

而且真实世界不像实验室，变量太多、反馈太慢、因果链太长。真正能被清楚证伪或证明的经验，其实很少。正因为很多事情既不能马上证明，也不能马上推翻，迷信才容易在这个缝隙里生长出来。

风水里有一部分其实是环境经验，比如采光、通风、动线、噪音、心理舒适度；但如果它变成完全不可验证的命运解释，就从经验变成了迷信。

1

第一层：把 AI 当聊天框

遇到问题就问它一句，得到一个答案，然后把这个答案当真理。这种用法看起来很先进，但本质上很容易变成新时代迷信。

如果我们只是问 AI 一个答案，然后不看证据、不看置信度、不做验证，就等于把过去求签、问大师、看风水，换成了问 AI。

2

第二层：把 AI 当生产力工具

让它写文案、做图、剪视频、生成菜单、回复点评、整理日报、写代码、做自动化。这一层已经很有价值，因为它真的能提高效率，降低成本，让一个人完成过去几个人的工作量。

3

第三层：把 AI 当持续进化的预测系统

不是只让它给答案，而是让它列证据、标置信度、记录反馈、持续更新。Codex 负责执行，Harness 负责规则和质检，角色蒸馏负责理解身边的人和自己。数据越多，反馈越密，预测越准。

这一层的 AI，不只是帮你“做事更快”，而是帮你“判断更准”。它先改变你自己：让你更理解自己的决策模式、情绪模式、拖延模式、合作模式。然后再改变你的小世界：你的店、你的团队、你的 IP、你的客户关系、你的工作流。

AI 当然不能替我们换来一个确定的命运。它真正能做的，是在充满变化和偶然的世界里，帮我们多看见一点线索，多校准一次判断，多完成一次行动，也多建立一段更可靠的合作。最后，AI 不是把人替掉，而是把人往前推一点：先让我们更理解自己，再让我们有能力慢慢改变自己身边的小世界。
